# Product Spec: 用户角色模块

**Issue:** #14
**Status:** Draft

Figma: none provided

---

## 1. 概述

实现用户与角色的多对多关联管理。用户可拥有多个角色，支持绑定、解绑、查询用户的角色列表、查询角色下的用户列表。

## 2. 问题

当前系统中 SysUser 和 SysRole 各自独立存在，没有关联关系。业务上需要将用户分配到角色，实现基于角色的权限管理基础。

## 3. 目标

1. 建立用户与角色的多对多关联关系
2. 提供绑定用户到角色的接口
3. 提供解绑用户角色的接口
4. 提供查询指定用户的所有角色接口
5. 提供查询指定角色下的所有用户接口

## 4. 非目标

- 不实现权限控制（仅建立用户-角色关联）
- 不实现批量绑定/解绑
- 不实现角色继承

## 5. 用户体验

### API 接口

路由前缀：`/user-role`

#### POST /user-role/bind
绑定用户到角色。

**请求体：**
```json
{
  "userId": 1,
  "roleId": 2
}
```

**响应：** `ApiResponse<bool>` — 绑定成功返回 true，已存在则返回 success: false

#### POST /user-role/unbind
解绑用户角色。

**请求体：**
```json
{
  "userId": 1,
  "roleId": 2
}
```

**响应：** `ApiResponse<bool>` — 解绑成功返回 true

#### GET /user-role/user/{userId}/roles
查询指定用户的所有角色。

**响应：** `ApiResponse<List<SysRole>>` — 返回用户关联的角色列表

#### GET /user-role/role/{roleId}/users
查询指定角色下的所有用户。

**响应：** `ApiResponse<List<SysUser>>` — 返回角色下的用户列表

### 验证规则

| 字段 | 规则 | 错误消息 |
|------|------|----------|
| userId | Required, > 0 | 用户ID不能为空 |
| roleId | Required, > 0 | 角色ID不能为空 |

### 行为规则

1. 绑定已存在的关联关系时返回 success: false, msg: "该用户已绑定此角色"
2. 绑定不存在的用户或角色时返回 400
3. 解绑不存在的关联关系时返回 success: false
4. 查询空角色返回空列表

## 6. 成功标准

1. 绑定用户到角色：成功后查询用户角色列表包含该角色
2. 重复绑定：返回 success: false
3. 解绑：解绑后用户角色列表不再包含该角色
4. 查询用户角色：返回正确的角色列表
5. 查询角色用户：返回正确的用户列表
6. 绑定不存在的用户：返回 400
